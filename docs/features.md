# Features in full

The README's Features list is the summary; this is each feature in full. Every config key named
here is in the README's [Configuration](../README.md#configuration) tables.

- **Rex sessions** — set `server = "local"` (or a host label from Rex's host list — remote servers are untested so far, see [`FOLLOWUPS.md`](FOLLOWUPS.md)) and a tab's terminals live in sessions on a Rex server — Superlogical's server-side terminal multiplexer, currently an invite-only beta you need installed. ⌘W, closing the window and quitting warden only detach: reopening the tab shows the same live screen, and the session is reachable from Rex's other clients too. The terminal takes the size of whichever device you last typed in. ☠ ends the sessions; ⏻ sleeps the project — its agents go to sleep and its sessions end, naming first anything that can't come back — and the dot ghosts until you wake one from the agent list. The dot shows whether the sessions exist, and opening the tab starts them; warden starts the local Rex server when a tab needs it. Sessions no tab claims, on every Rex server warden is connected to (at launch, those your tabs name and any a past session was made on), are listed under `Rex · <server>` in each window with a Rex tab, so none is hidden. A Rex tab's dot, ☠ and ⏻ come from Rex, so its `probe`, `kill` and `suspend` aren't run. Tabs without `server` stay plain terminals.
- **Agent tabs** — a Rex tab's main pane lists its agents in a column to its left, one per Rex window, so a window opened in Rex.app or on the phone shows up too. A summary block below the pane shows the selected agent's topic, your last ask (and any short reply to its options after it, like `→ b`), what it's doing — or, in bold, what it needs from you — and what it last did, rewritten after each turn by a short Haiku digest, in the project's colour, and a tile in that colour sits at the list's foot. Above the rows, a tally counts the agents needing you, working and asleep, and clicking **needs you** goes to the next one waiting. **+ New tab** (**⌘T**) starts another agent with the tab's `cmd`; each row shows its agent's status and title, renames on double-click, and drags into named groups that fold. From either pane of the tab, **⌘↑** / **⌘↓** (or **⌘K** / **⌘J**) step through the agents and **⌥⇧⌘↑** / **⌥⇧⌘↓** move one within its group, and **⌘W** closes it (**⌥⌘W** closes the project tab instead). A row reads as unread until you've opened what its agent last did, and its dots read as a project row's do: amber when the agent needs you (blocked, or finished and not yet opened), cyan for its session — pulsing while it works, a ghost while asleep. An agent needing you while its tab is hidden also badges the project's row and raises a banner.
- **Sleep and wake** — click an agent's cyan dot for **☠ Close** or **⏻ Sleep** (**⌥⌘S**); sleeping closes the agent but keeps it in the list as a ghost, whose click offers **☠ Close**, and selecting it resumes its conversation (set `resume` to resume through a wrapper). From a row's **⋯** (or right-click), **Fork** (**⌥⌘T**) opens a new tab just below it that picks up the same conversation as a separate branch, leaving the original as it was (Claude Code agents). Closing moves it to the **Closed** fold, and **⌘⇧T** reopens the last one closed. After quitting warden or Rex, a project's agents come back asleep: opening the project leaves its pane blank until you select one. **Tab ▸ Sleep Server** sleeps every agent on a Rex server on this Mac and stops it, naming first anything that can't come back. Sleep, Fork and the summary's ask and last-said lines need the agent hook that `/warden:install` wires, and the hook needs `jq`.
- **A window per `[[window]]`** — native macOS windows, each with a colour + title banner, a draggable sidebar, and the terminal under an overlay titlebar. The **Window** menu lists every configured window — raise an open one or reopen one you've closed (**⌘⇧T** reopens the last closed). **New Window…** (**⌥⌘N**) adds one, and right-clicking a window's banner renames or recolours it in place (its terminals keep running) or deletes it — each written to the config, comments kept.
- **Persistent, not last-window-quit** — warden opens the windows you mark `open_on_start` (default all) and shows a **home surface** when none are open, listing every configured window so you can raise or reopen one with a click. Scripts open one by title: `open 'warden://open?window=work'` launches warden if needed and opens (or focuses) that window, and `&tab=<id or title>` selects a tab in it — bind that to a hotkey to jump straight to a project. A window or tab that doesn't exist is named in an alert. Closing the last window never quits it — **⌘Q** does.
- **Project tabs** — each tab is a real terminal in a working directory. `load_on_open` tabs spawn at launch and keep running; the rest spawn lazily on first focus — or, with `remember_tabs`, come back loaded if they were open when you quit. Tabs can be **grouped** into labelled sidebar sections.
- **Project trees** — point a `[[window.root]]` at a directory (e.g. `~/Developer`) and warden auto-discovers every git project under it, rendering them as a collapsible tree of tabs — no per-project config needed. Set `probe`/`kill`/`suspend` on the root (see the session-presence probes below) for a session dot on every discovered project.
- **Live hot-reload** — edit the config and windows and tabs are added, removed, recoloured, and re-sectioned live on save. A missing config offers to create a starter one and an invalid one shows the error, both on the **home surface**; a parse error mid-edit instead keeps the last-good windows up behind an error banner. The **Config** menu opens the config file in your default editor or reveals it in Finder.
- **Tab-row affordances** — a letter/colour tile and a **live/cold dot** (filled when the terminal is spawned, hollow when cold). Hover a live dot for a ✕ that **unloads** the tab; it respawns a fresh shell on next focus.
- **Pop-out tabs** — pop the active tab into its own banner-only window with **⌘⇧O** (or hover the row's letter tile and click its pop-out icon). It's **session-preserving**: the live terminal, its scrollback, and the running process move across untouched — no restart. Closing the popped-out window returns the tab to where it came from (reopening its origin window first if you'd closed it), and the pop-in icon on its sidebar tile brings it back. A popped-out window remembers the size and position you last gave it. A split tab pops out with both panes, their sides and the divider ratio intact, and its divider drags within the same limits as `split`'s `size`.
- **Splits** — a `split` table (global, per-window, per-root, or per-tab) opens a tab already split, second pane on either side, at a declared size, running a declared command beside the tab's own. **⌘D** (or Tab ▸ Split) on a tab with no split saves `split = true` to that tab in your config, and the second pane opens beside the running terminal. Either way you get a thin draggable divider between the two terminals, and **⌥⌘←** / **⌥⌘→** move the keyboard between them; to close a split, type `exit` in the second shell, right-click it ▸ Close Pane, or remove it from the config. A dragged ratio holds only until the tab's terminals relaunch (unload, hot-reload, or app restart), then it snaps back to the declared size. **⌘W** and **⌘⇧O** act on the whole tab from either pane: unloading drops both terminals, popping out takes both with it. On a Rex tab the second pane is a **scratch column**: `split.pane` stacks several shells in it, **⌘D** in one splits it above (right-click for **Split Below**) and right-click ▸ Close Pane closes it, **+** (or **⌃⌘T** from either pane) adds a scratch tab you switch between from the strip on top, the shown tab's **×** closes it — closing the last one opens a fresh one in its place, so the column only goes when you remove it from the config — and splits made in Rex.app show up too. A column holding more than one shell can't pop out yet.
- **Terminal right-click menu** — right-click a terminal (⌃-click while a program such as tmux or vim has the mouse) for **Copy**, **Paste**, **Split** (**Split Above** and **Split Below** in a Rex scratch shell), **Close Pane** in a split's second pane, and, on a split tab, **Size ▸**: preset shares plus the one the tab inherits, the current one ticked. Picking a size saves it to that tab's `split` in your config. Right-clicking a divider offers the same sizes; on a divider inside a scratch column they set the lower (or right) pane's share, which Rex keeps with the session.
- **Live terminal affordances** — URLs and OSC 8 hyperlinks in a terminal are **clickable**: hold **⌘** and hover one for a hand cursor, **⌘-click** to open it — even inside a program that has the mouse, such as Claude Code or tmux with `mouse on`. Links are **screened first**: web and mail links open directly, a custom-scheme link asks before launching its handler app unless `trusted_link_schemes` lists it, and a target that could run code (an app, a script, an executable file) or hides invisible characters is refused, with a **Copy Link** option. And when a tab's process exits (the shell quits, an agent finishes), the tab goes **cold** — the dot empties and the row respawns a fresh shell on next focus.
- **Notifications** — a background tab that rings the bell or emits a desktop-notification escape (OSC 9 / OSC 777) gets an amber badge, and a desktop notification additionally raises a macOS banner; the badge clears on focus.
- **Sidebar search** — the field above the tab list narrows it as you type, matching tab titles, folder paths and group names (folders open to show matches). **⌘⇧F** jumps into it from a terminal; **↑**/**↓** pick a match, **Enter** opens it, **Esc** clears the search and returns you to the terminal. Clicking a match opens it and keeps the search focused, so you can keep narrowing.
- **Collapse the sidebar** — the button beside the traffic lights (or **⌃⌘S**) hides it, leaving a thin strip with the tab's title. Rest the pointer on the window's left edge to slide it in; moving onto the terminal hides it again. Each window remembers its own choice.
- **Keyboard navigation** (the **Tab** menu) — **⌘⇧[** / **⌘⇧]** cycle the previous/next *loaded* tab (cold tabs are skipped) and **⌘1–⌘9** jump to a position; **Tab ▸ Cycle Tabs with ⌘1/⌘2** (or `tab_digit_keys = "cycle"`) makes **⌘1** / **⌘2** cycle instead (jumps shift to **⌘3–⌘9**). **⌘W** unloads the active tab (in a tab with agents it closes the selected agent; **⌥⌘W** always unloads the tab), **⌘⇧W** closes the window, and **⌘⇧O** pops the active tab into its own window. **⌘⇧S** suspends the active tab's session and **⌘⇧K** terminates it — the first ⌘⇧K arms the tab's confirm row, a second one within 4s confirms.
- **CLI** — `warden validate` prints the resolved windows and tabs and any warnings, exiting 0 (ok), 1 (load/parse/validation error) or 2 (usage); `warden fmt [--check]` rewrites a config in warden's house TOML style — consistent indentation, aligned `=`, section spacing.

## Session-presence probes

A plain tab (no `server`) gets a session dot from a `probe` command — any check that exits 0 when
the tab's session exists, such as a tmux session named after the tab:

```toml
probe = "tmux has-session -t {title}"
```

so the dot is cyan while the session is up, a ghost when the probe exits 3 (gone but restorable),
and hollow otherwise — independent of whether warden's own terminal surface is loaded. Unloaded
tabs with a cyan or ghost dot are gathered in a collapsed **Background** section at the top of the
sidebar. `probe_interval` sets the idle poll in seconds (default 5; `0` probes only on events such
as tab focus or hot-reload); probes also run in quick bursts after each event, so keep the probe
command fast. Internals: [probing.md](probing.md). Name a tool outside the system paths by
**absolute path** — a Finder/Dock launch doesn't have your shell's exports.

A plain tab's optional `kill` and `suspend` commands end the session the dot represents: click the
cyan dot once to arm it, then pick **☠ destroy** (runs `kill`) or **⏻ suspend** (runs `suspend`) —
either way the command runs fire-and-forget (cwd = the tab dir) and the tab unloads. Clicking a
ghost on an unloaded tab arms **☠** too, which discards the restorable session. The dot controls
need `probe`; ⌘⇧K / ⌘⇧S run `kill` / `suspend` on any tab.

The dot works in reverse too: when the probe reports the session **gone** on a tab whose terminal
is still live — hollow or ghost alike — the same dot becomes a one-click **start**: warden types
the tab's `cmd` into the existing shell, so a dead or crashed agent session restarts (or restores)
in place — scrollback preserved, no terminal respawn.

Not yet built (see [`FOLLOWUPS.md`](FOLLOWUPS.md)): ad-hoc `cmd+T` / `cmd+N` tabs and windows for
plain (non-agent) tabs.
